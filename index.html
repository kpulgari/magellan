What makes Magellan magical? 🔍

Magellan is an open-source Chrome extension that brings conversational AI to your web browsing experience. Ask questions about any webpage or PDF and get AI-powered answers with smart citations and visual highlights.

🧠

AI-Powered Search

Ask questions about any webpage and get instant answers.

🔎

Multiple Search Modes

  • Page Context: Search only within the current page content
  • Blended: Search page first, then use general knowledge if needed
  • General Knowledge: Use only general knowledge, ignore page content
📄

Document Upload

Upload PDF files for analysis.
Smart Context: Uses uploaded PDFs as page context for searches.

Get Started in Seconds

Using Magellan is incredibly simple. Follow these easy steps to transform your browsing experience.

1

Install Extension

Click the "Add to Chrome" button and install Magellan from the Chrome Web Store. Ensure you have a free Gemini API key from Google AI Studio.

2

Search Intelligently

Open Magellan on any webpage and type what you're looking for. Think concepts, not just keywords!

3

Get Answers

Receive precise, contextual answers with source highlighting.
