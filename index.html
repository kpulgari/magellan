Product

Your AI Superpower

Magellan transforms your browser into an intelligent research and analysis tool. Free, open-source, and privacy-focused.

🧠

Intelligent Search Modes

Choose the right context for every question. Page Context grounds the AI exclusively in the current page's text - ideal for precise lookups and fact-checking against what's actually on screen. Blended combines page content with the model's broader knowledge, great for enriching what you're reading with deeper context. General Knowledge ignores the page entirely and draws purely from the AI - perfect for background research or questions unrelated to the current content.

📄

Document Analysis

Upload PDF, TXT, DOC, DOCX, MD, and RTF files. Ask questions about document content with full context awareness.

📚

Smart Citations & Highlights

Automatic citations with visual highlights on the page. Navigate between sources and jump directly to relevant sections.

🔄

Real-time Web Search

Optional real-time web search for current events and up-to-date information. Toggle on/off as needed.

🤖

Flexible AI Models

Choose from hundreds of AI models via OpenRouter. Switch between models optimized for speed, accuracy, or specific capabilities.

💬

Persistent Chat History

Conversation history saved per browser tab. Each tab maintains its own separate chat context.

🎨

Customizable Interface

Light and dark themes with system sync. Collapsible input section for maximum screen space.

🔒

Privacy-Focused

100% free and open-source. No data harvesting. Your API key stays local. All processing through your chosen provider.

Workflow

Get Started in Seconds

Using Magellan is incredibly simple. Follow these easy steps to transform your browsing experience.

1

Install Extension

Click the "Add to Chrome" button and install Magellan from the Chrome Web Store. Get your API key from OpenRouter.

2

Search Intelligently

Open Magellan on any webpage and type what you're looking for. Think concepts, not just keywords!

3

Get Answers

Receive precise, contextual answers with source highlighting.
